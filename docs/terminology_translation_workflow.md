# 术语统一与英文翻译执行计划

TAG：当前任务为 Step 3（作者已确认术语英文译法；开始在 `_compare.tex` 对照稿中逐段添加英文翻译）。

本文档承接 `docs/paper_revision_plan.md` 中当前任务 4 和任务 5：

- 任务 4：整理术语中英文对照表。
- 任务 5：按术语表统一全文英文翻译。

该任务可能跨多个 session 执行。每次新 session 默认先阅读本文档和 `docs/paper_revision_plan.md` 的当前 tag，再从尚未完成的 step 继续。

## 1. 目标

导师的核心要求是：论文中的用词尽量不要凭感觉自造，而应尽量使用领域内常用、较公认的表达。

具体目标包括：

1. 先通读中文稿，提炼全文高频术语、核心概念和反复出现的解释性词组。
2. 在中文版本中先统一表达：同一概念尽量使用同一中文说法，避免前文一种说法、后文另一种说法。
3. 对提炼出的中文术语和固定词组建立中英文对照关系。
4. 对不确定英文表达检索相关英文论文，优先采用业内更常见的说法。
5. 基于定稿术语表翻译英文版本，并在翻译后检查全文、图表、caption、表头中的用词一致性。

说明：

- 不是全文每个短语都必须作为术语。
- 但反复出现、承担论文主线含义的解释性语言，也应尽量固定表达。
- 中文稿先统一后，英文翻译阶段的术语一致性压力会明显降低。

## 2. 执行流程

### Step 1：中文稿用词检查与中文术语提炼

目的：先保证中文版本在概念层面统一。

输入范围：

- `manuscripts/zh/sections/00_frontmatter.tex`
- `manuscripts/zh/sections/01_introduction.tex`
- `manuscripts/zh/sections/02_related_work.tex`
- `manuscripts/zh/sections/03_method.tex`
- `manuscripts/zh/sections/04_experiments.tex`
- `manuscripts/zh/sections/05_conclusion.tex`
- `manuscripts/zh/tables/src/*.tex`

执行内容：

1. 通读全文，提炼中文术语、方法名、实验设置、指标名、疾病名和反复出现的解释性词组。
2. 检查同一概念是否存在多个中文写法。
3. 区分“必须固定的术语”和“建议固定的解释性词组”。
4. 必要时先修改中文稿，使中文概念前后一致。
5. 创建或更新 `docs/terminology_glossary.md`，记录中文术语底稿。

输出：

- 中文术语候选表。
- 中文混用问题清单。
- 已统一后的中文写法。
- 待英文翻译和文献确认的术语清单。

停止点：

- 作者 review 中文术语表和中文统一建议。
- 作者确认后进入 Step 2。

### Step 2：英文译法初定与文献口径确认

目的：为中文术语表中的每个术语确定英文主译法。

执行内容：

1. 为 Step 1 中列出的中文术语和固定词组给出英文候选译法。
2. 对常规术语采用领域通用表达。
3. 对不确定术语检索相关英文论文，确认更常用说法。
4. 在 `docs/terminology_glossary.md` 中记录最终推荐英文、缩写、使用范围和必要备注。
5. 标明不推荐或需要避免的英文写法。

需要重点查证的类型：

- 领域设置类术语。
- 方法模块名称。
- 跨域泛化相关术语。
- 隐私保护和差分隐私相关术语。
- 医学眼底疾病识别相关术语。

输出：

- 定稿版中英文术语表。
- 文献口径备注。
- 英文翻译时必须遵守的主译法。

停止点：

- 作者 review 定稿术语表。
- 作者确认后进入 Step 3。

### Step 3：按术语表翻译英文版本

目的：在术语表约束下完成英文稿。

执行载体：

- 原中文稿保持不动。
- 已复制 `manuscripts/compare/main_compare.tex`、`manuscripts/compare/sections/*_compare.tex` 和 `manuscripts/compare/tables/src/*_compare.tex` 作为中英对照翻译稿。
- 翻译阶段先在每段中文后追加对应英文译文，便于作者逐段校对。
- 校对完成后，再删除中文段落并保留英文内容，形成最终英文版本。

执行内容：

1. 按定稿术语表翻译摘要、引言、相关工作、方法、实验、结论。
2. 同步翻译图题、表题、caption、表头和必要的图内英文。
3. 保留原 LaTeX 结构、公式、引用、标签和图表引用。
4. 对术语表中已有词组强制使用主译法。
5. 对非术语解释性语言，尽量保持同一上下文下表达一致。

输出：

- 英文版论文 `.tex` 文件或英文分支内容。
- 翻译过程中发现的新增术语，回填到 `docs/terminology_glossary.md`。

停止点：

- 作者 review 英文稿的学术含义和整体表达。
- 作者确认后进入 Step 4。

### Step 4：最终一致性检查

目的：在提交导师前完成自查。

执行内容：

1. 检查术语表主译法是否全文一致。
2. 检查是否出现术语表中列出的避免写法。
3. 检查同一缩写首次出现是否完整定义。
4. 检查摘要、贡献、方法、实验、结论中的核心用词是否一致。
5. 检查图题、表题、caption、表头是否与正文一致。
6. 检查数据集划分、指标名、方法名、疾病名等是否统一。
7. 必要时重新编译 PDF，确认英文排版和引用正常。

输出：

- 最终英文稿。
- `docs/terminology_glossary.md` 定稿版。
- 术语一致性检查说明，可附在术语表末尾。

## 3. 最终交付物

最终建议准备三类材料：

1. `docs/terminology_glossary.md`：中英文术语对照表。
2. 英文版论文：按术语表统一后的翻译版本。
3. 术语一致性检查说明：说明已检查全文、图表、caption 和表头。

## 4. 跨 Session 接手规则

每次新 session 开始时：

1. 先阅读 `docs/paper_revision_plan.md` 的当前任务状态。
2. 再阅读本文档，确认当前应执行的 step。
3. 如果 `docs/terminology_glossary.md` 已存在，优先以该文件为术语依据。
4. 不跳步：Step 1 未确认前不进入英文文献定稿；Step 2 未确认前不全文翻译；Step 3 未完成前不做最终一致性检查。
5. 每完成一个 step，在 `docs/paper_revision_plan.md` 或本文件中记录进度。
