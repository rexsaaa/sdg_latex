v2 摘要已经导师认可并冻结，后文展开必须围绕这一版摘要重新对齐。导师认可的层层递进结构如下：

- 进一步：跨机构部署存在数据分布偏移，引出泛化问题；常见跨域方法预设可访问目标域或多源域数据，这一前提在真实医疗场景中难以满足。
