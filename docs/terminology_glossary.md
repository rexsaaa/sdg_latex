# 中文术语统一清单

TAG：Step 1 中文术语统一暂时完成。

本文档根据当前暂存区中摘要、引言、相关工作、方法、实验、结论以及图表 caption 的已核查修改整理，用于记录中文稿中 2 次及以上出现的固定术语、同义表达和高频解释性描述。

说明：

- “当前主要采用写法”是中文稿中优先保持一致的表达，通常只列 1 个核心写法。
- “同义写法”用于语义通顺、不同语境下不宜机械重复主要写法的情况。
- “说明”记录主要写法和同义写法各自适用的位置或语境。

## 1. 核心任务与应用场景

| 概念 | 当前主要采用写法 | 同义写法 | 说明 |
| --- | --- | --- | --- |
| 论文主任务 | 多标签眼科疾病识别 | 多标签识别、多标签图像识别、多标签识别任务 | 摘要、引言贡献、方法总述和实验分析中用“多标签眼科疾病识别”指代本文任务；在上位背景或自然图像相关工作中可用“多标签图像识别”“多标签识别”。 |
| 应用入口 | 早期眼底筛查 | 眼底筛查 | 摘要和引言开头用“早期眼底筛查”；讨论方法路线或筛查规模时可简化为“眼底筛查”。 |
| 临床任务落点 | 眼科疾病诊断 | 眼科疾病识别、眼科疾病诊断与预测 | 强调临床应用价值和诊断场景时用“眼科疾病诊断”；描述模型任务、方法能力或已有工作时用“眼科疾病识别”。 |
| 模型输入与样本 | 眼底图像 | 医疗图像 | 数据样本、模型输入和数据集描述中用“眼底图像”；泛化到医学场景或隐私背景时用“医疗图像”。 |
| 临床多病现象 | 多疾病共存 | 眼科疾病共存、疾病共存关系 | 描述同一眼可能同时存在多种疾病时用“多疾病共存”；在 ARC 动机和相关工作中可用“眼科疾病共存”“疾病共存关系”。 |
| 图像病变线索 | 疾病相关区域 | 病变区域、病灶特征 | CAM、注意力和可视化分析中用“疾病相关区域”；医学图像内容描述可用“病变区域”“病灶特征”。 |
| 模型任务效果 | 识别性能 | 多标签识别性能 | 实验和结果分析中主要用“识别性能”；涉及传统分类器、分类头、损失函数或已有分类任务时可保留“分类”。 |

## 2. 泛化、跨域与数据划分

| 概念 | 当前主要采用写法 | 同义写法 | 说明 |
| --- | --- | --- | --- |
| 泛化上位问题 | 域泛化 | 跨域泛化 | 方法章节描述训练设置和性能来源时用“域泛化”；摘要、引言和实验中强调跨数据集、跨机构表现时可用“跨域泛化”。 |
| 单源泛化设置 | 单域泛化 | 单一源域训练 | 方法框架和设置名称用“单域泛化”；实验条件中可写“单一源域训练”。 |
| 分布变化问题 | 域偏移 | 分布差异 | 跨机构或跨数据集部署问题用“域偏移”；解释源域/目标域差别时可用“分布差异”。 |
| 源数据域 | 源域 | 单一源域、源域原始图像、源域增强图像、训练集 | 泛化术语用“源域”；强调 SDG 约束时用“单一源域”；DFE 输入中固定用“源域原始图像”和“源域增强图像”；实验数据集可用“训练集”。 |
| 目标数据域 | 目标域 | 未知域、跨域泛化数据集、测试集 | DA 或图示分布对比中用“目标域”；DG/SDG 泛化目标主要用“未知域”；实验数据集可用“测试集”。 |
| 域内测试 | 域内泛化 | ODIR域内泛化 | ODIR 的 Off-site 到 On-site 评估统一称为“域内泛化”。 |
| 跨数据集测试 | 跨域泛化 | 跨域泛化数据集 | RFMiD 和 EDID 作为独立泛化测试集时用“跨域泛化数据集”。 |
| 数据划分名称 | Off-site | Off-site test | 表头和指标引用中用“Off-site”；数据集划分说明中可用“Off-site test集”。 |
| 数据划分名称 | On-site | On-site test | 表头和指标引用中用“On-site”；数据集划分说明中可用“On-site test集”。 |
| 标签对齐空间 | 共有标签空间 | 三类共有标签空间、D/A/M三类、D/G/M三类 | RFMiD 与 ODIR 对齐 D/A/M；EDID 与 ODIR 对齐 D/G/M；实验设置中用“共有标签空间”。 |
