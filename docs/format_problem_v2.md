# 全文格式问题排查 v2.0

基于导师反馈和全文排查，以下为需要修复的格式问题清单。

---

## P0：导师已指出的问题

### F1：引用与正文未打空格

**现状：** `\hyperref` 引用命令前后直接紧贴中文正文，无空格分隔。

**典型示例：**
```
问题\hyperref[_Ref213949872]{{[}14{]}}。早期方法
ML-GCN\hyperref[_Ref213949382]{{[}10{]}}根据标签
```

**应改为：** 引用前加空格，使引用编号与前文有视觉间距。引用后如果紧跟标点则不加。

**涉及文件：**
- `02_related_work.tex`（最密集，约15+处）
- `03_method.tex`（约3处）
- `04_experiments.tex`（约10+处）
- `01_introduction.tex`（约5处）

### F2：公式无编号

**现状：** `03_method.tex` 中所有12个公式均使用 `\[ \]` 无编号形式。

**涉及公式（行号）：**
- 行22：CAM计算公式
- 行27-28：CAM引导特征公式（两个公式紧接，用两个`\[\]`块）
- 行34-42：掩码矩阵公式
- 行46：域不变特征公式
- 行57-59：自注意力公式
- 行65-67：交叉注意力公式
- 行73-80：注意力一致性损失公式
- 行86-87：分类损失公式
- 行104-105：差分隐私定义公式
- 行109-110：梯度裁剪公式
- 行114-115：噪声乘数公式

**修复方案：** 将 `\[ \]` 改为 `\begin{equation} \end{equation}` 并添加 `\label`。多行公式考虑用 `align` 环境。

### F3：公式后标点与分段问题

**现状：** 公式 `\]` 结束后紧跟空行，然后新段落以"其中"开头。排版规范中，公式后的解释文字应与公式同属一段。

**典型示例：**
```latex
\]

其中\(A_{k}\)是骨干网络...
```

**修复方案：** 删除公式后的空行，使"其中..."紧接公式不另起段落。

**涉及位置：** `03_method.tex` 中几乎所有公式后都有此问题（共11处）。

## P1：排查发现的重要问题

### F4：中英文混排空格缺失

**现状：** 英文单词/缩写与中文之间缺少空格，不统一。

**典型示例：**
```
1x1卷积、ReLU激活和Sigmoid函数    ← 缺空格
使用 Transformer 注意力机制        ← 有空格（正确）
ODIR数据集                         ← 缺空格
```

**修复方案：** 统一规则：英文与中文之间加空格。涉及全文。

### F5：英文标点 vs 中文标点 / 括号混用

**现状：**
- `et al.` 后有时跟英文句点再接中文，有时直接接中文逗号
- 英文括号 `()` 与中文括号 `（）` 混用：
  - 正文中术语全称用中文括号（正确）：`卷积神经网络（CNN）`
  - caption 中子图引用用英文括号：`(a)-(h)`
  - 正文中 `base model（...）` 用中文括号

**修复方案：** 统一规则：
- 正文中包裹英文缩写/术语全称：用中文括号 `（）`
- caption 中子图引用标记：统一用英文括号 `(a)`
- `et al.` 后统一加空格再接引用

### F6：引号样式不统一

**现状：**
- `04_experiments.tex` 行111 使用 LaTeX 引号 ` ``...'' `（正确）
- 需检查是否有其他地方用直引号 `"..."`

**已确认：** 当前只有一处引号（行111），使用正确的 LaTeX 格式 ` ``先线性衰减后恒定'' `，无需修复。

### F7：列表/编号风格混杂

**现状：**
- 第1章贡献：`\begin{sloppypar}` + 手写 `1.` `2.` `3.`
- 第4章消融实验：`\begin{itemize}` + `\item`
- 第4章 E 节小节标题：手写 `（1）（2）（3）（4）`
- 第4章 E 节优化策略：手写 `1.` `2.`

**修复方案：** 
- 贡献列表：改为 `\begin{enumerate}` 
- 实验小节标题 `（1）（2）...`：这更像小节标题而非列表项，保留手写格式或改为 `\paragraph` 均可，需讨论
- 模块消融的 itemize：保留

### F8：术语首次出现的全称-缩写格式不统一

**现状：**
- 有的用"中文全称（English Full Name, ABBR）"：`自适应标签-特征关联性构建模块（Adaptive label-feature relevance construction, ARC）`
- 有的用"中文全称（ABBR）"省略英文全称：`CAM（Class Activation Mapping）`——这里反过来了，是缩写在前

**修复方案：** 统一为"中文全称（English Full Name, ABBR）"格式。

### F9：Caption 句末标点

**现状：**
- figure caption：均以 `。` 结尾（已统一✓）
- table caption：均以 `。` 结尾（已统一✓）

**结论：** 无需修复。

### F10：Caption 中子图引用的连接符

**现状：**
- `(a)-(h)`（短横线）和 `(a)--(h)`（双短横线/en-dash）混用

**典型示例：**
```
04_experiments.tex 行12: 其中(a)-(h)分别代表
04_experiments.tex 行79: 其中(a)--(j) 为不同测试样本
03_method.tex 行10: 由 (a)--(c) 组成
```

**修复方案：** 统一为 `(a)--(h)` 形式（LaTeX en-dash）。

### F11：公式排版——两个 `\[\]` 紧接

**现状：** `03_method.tex` 行27-28：
```latex
\[F_{guide}^{ori} = ...,
\]\[F_{guide}^{aug} = ...,\]
```
两个独立公式用 `\]\[` 直接拼接，排版不规范。

**修复方案：** 改为 `align` 环境合并为一组公式。
